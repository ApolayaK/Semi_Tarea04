# ⚠️ Advertencia sobre actualizaciones

Durante el desarrollo, se han identificado **problemas al subir actualizaciones a GitHub**.  

Se recomienda:

- Reiniciar el dispositivo, o  
- Limpiar el caché del navegador o aplicación.

## ✅ Recomendaciones

- **Subir cambios en partes pequeñas** para evitar errores.  
- **Verificar** que cada parte se cargue correctamente antes de continuar.  
- Por ejemplo:  
  - Subir una parte hoy.  
  - Mañana, cuando tenga el dispositivo disponible, **subir la siguiente parte y finalizar**.
